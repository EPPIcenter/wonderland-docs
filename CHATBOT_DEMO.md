# Funder demo script — docs AI chatbot

Use this short script to show that scientists can ask natural-language questions and get grounded answers with links into the MAD4HATTER docs.

**Live site:** https://eppicenter.github.io/wonderland-docs/

## Setup before the call

- Open the live docs in a clean browser window.
- Confirm the Ask widget appears (bottom-right).
- Have these four questions ready (or paste them one at a time).

## Demo flow (about 3–4 minutes)

1. **Getting started**  
   Ask: *How do I install and get started with MAD4HATTER?*  
   Show: short structured answer → click a citation → lands on Getting Started.

2. **Running the pipeline**  
   Ask: *How do I run the MAD4HATTER pipeline?*  
   Show: citation to Running the Pipeline / execution docs.

3. **A specific parameter**  
   Ask: *What parameters control amplicon or pool configuration?*  
   Show: citation to Advanced Pipeline Parameters.

4. **Outputs / QC**  
   Ask: *Where are pipeline outputs written, and how do I interpret QC?*  
   Show: citations to Pipeline Outputs and/or QC.

## Talking points

- Answers are grounded in our published documentation, not generic model memory.
- Every answer can link back to the authoritative page for verification.
- This is a **proof of concept** on the free tier (core docs only; light usage).
- With funding we can expand indexed content, usage limits, and analytics on unanswered questions to improve the docs.

## If something fails live

- Fall back to the built-in Material search, or open the cited page manually from the nav.
- Note that the PoC is capped (≈100 messages/month on free tier); avoid hammering the widget during prep.
